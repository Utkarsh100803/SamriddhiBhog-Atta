JavaScript Features

All JS is in script.js — a single IIFE (Immediately Invoked Function Expression) in strict mode. No frameworks, no dependencies.

FunctionWhat It Does
initNavbar()Adds .scrolled class to navbar when scrollY > 20px, triggering box-shadow
initMobileNav()Hamburger opens right-side drawer (300px). Overlay click, close button, and mobile link clicks all close it. Body scroll locked while open.
setActiveLink()Reads current filename from URL, adds .active class to matching nav and mobile links
initScrollReveal()IntersectionObserver on all .reveal, .reveal-left, .reveal-right, .reveal-scale elements. Adds .visible class on entry, then unobserves. Threshold: 0.08, rootMargin: "0px 0px -40px 0px"
initStaggeredGrids()Adds .stagger-1 through .stagger-6 (cycling) to children of major grids to create wave-in effect
initScrollProgress()Injects a .scroll-progress bar element (3px red, fixed top). Width = scrollY / (scrollHeight - clientHeight) × 100%
initCounters()Animates [data-count] elements from 0 to their target value when scrolled into view. Supports data-prefix and data-suffix attributes.
initProductFilter()Filter tabs on products page show/hide cards by data-cat. Filtered-in cards replay heroSlideUp animation.
initCardTilt()3D mouse-tracking tilt on .why-card, .product-card, .recipe-card. Max ±4deg rotation. Resets on mouseleave.
initWhatsApp()Attaches click handler to .whatsapp-float-btn if no href, opens WhatsApp with preset message
initContactForm()Intercepts #contact-form submit. Simulates 1.2s send delay, shows "Message Sent ✓" in green, resets after 3.5s
initDealerForm()Same simulation for #dealer-form on dealership page
initSmoothScroll()Smooth scrollIntoView for all a[href^="#"] anchor links

Design Patterns

Section Label Pattern

Every section starts with a .section-label — a small uppercase label in --red at 0.72rem with 0.2em letter-spacing. It has a 40px red line drawn via ::before that animates in (0→40px) when the element enters the viewport.

Dark Section Pattern

On dark backgrounds (maroon/maroon-dark), section labels switch to --gold color. The ::before line also turns gold. Headings become #fff. Body text becomes rgba(255,249,240,.65) — a warm off-white.

Product Pack Visual

Each product card uses a CSS-drawn pack: colored rectangle (100×140px), border-radius 8px, 3 text lines (S.BHOG brand, product name, weight), default rotation of -3deg that resets to 0 + scale(1.05) on card hover.

Stat Display Pattern

Stats use Spectral display font at 2.8rem for the number + Josefin Sans 1rem uppercase label below. Appears in About Teaser (homepage), About page hero, and Infrastructure page.

WhatsApp-First Commerce

Every product CTA opens WhatsApp with a pre-filled message (wa.me/919999999999?text=I+want+to+order+...). No e-commerce cart. The WhatsApp float button is always visible on all pages.

Comparison Table

3-column grid: Us (cream/red-border left col) · "VS" center divider · Them (dark translucent right col). On the Us side, checkmarks are --gold. On the Them side, question marks are rgba(255,255,255,.35). Background is --maroon.

Navigation

Fixed navbar (72px tall), cream background, appears with navDrop animation. Scrolling past 20px adds a soft box-shadow. Active link + hover both show a --red underline that animates width 0→100%.

Footer Structure

4-column grid on --cream background: Brand column (1.2fr) with tagline + WhatsApp button + location · Products (1fr) · B2B (1fr) · Help (1fr). Column headings at 0.72rem uppercase in --red.
