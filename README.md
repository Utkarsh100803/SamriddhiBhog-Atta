# Samriddhi Bhog - Flour Mills Website

A professional website for Samriddhi Bhog, a trusted flour mill business established in 2004, specializing in stone-ground atta, besan, sattu, and suji products.

## Features

- 🏠 **Homepage** - Video hero section with company introduction
- 📋 **About** - Company history and values
- 🛍️ **Products** - Complete product catalog
- 👥 **Clients** - Customer testimonials and partnerships
- 📜 **Certifications** - Quality certifications and compliance
- 🚚 **Exports** - International business information
- 🤝 **Dealership** - Partnership opportunities
- 💼 **Career** - Job opportunities
- 📞 **Contact** - Contact information and location

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties
- **JavaScript** - Interactive functionality
- **Font Awesome** - Icons and visual elements
- **Responsive Design** - Mobile-first approach

## Key Highlights

- Pure stone-ground flour products
- Zero adulteration guarantee
- Fiber-rich, cold-press milled products
- Home delivery available
- Trusted by families since 2004

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through the different sections using the menu
